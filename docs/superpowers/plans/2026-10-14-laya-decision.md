# Laya 独立决策层实施计划

> 执行方式：本会话按步骤实施、验证和审查；用户已确认独立评审与回测方案。

**Goal:** 接入本地 Laya 的大乐透专用训练、独立选票与冻结历史评估。

**Architecture:** 构建严格时间边界的数据，复用本地训练脚本，Laya 评分候选后选择一张。独立 JSON 保存实验和部署版本，原 9 个模型、已有 DB 结果及 GitHub 预测流程保持独立。

**Tech Stack:** Python unittest、SQLite、现有 Laya/MPS 环境、Vue 3。

## 实际验证

- 29 项 Laya 单元测试、原基础测试、Node 20 前端构建通过。
- 小样本 64 候选/1 轮、冻结评估 360 候选/4 轮、最新可用版 522 候选/4 轮均实际完成；正式专用决策头各约 29 MB。
- 冻结测试 10 期/90 候选：选票中奖 1 注，奖金 5 元，ROI -75%；Brier 0.105195，高于常数基线 0.099390。未晋升集成。
- 模型重新加载及推理通过；原 DB、预测/结果、9 模型权重未改动，26117 预测仍为零。
- 代码审查通过，冻结成绩与本期显式决策分别保存，所有评分加载验证版本/截止/摘要。
